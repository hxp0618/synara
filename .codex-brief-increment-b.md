## Goal

Upgrade Kubernetes warm pools from best-effort to a hard minimum-idle guarantee so interactive agents
start in seconds: a new `min_idle_units` floor per worker pool, replenished with priority BEFORE cold
execution Pods, exempt from demand eviction, with a deficit metric and alert.
